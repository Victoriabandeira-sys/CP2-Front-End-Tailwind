# CP5 – Front-End Design | Tailwind CSS

## Como executar

**1. Clone o repositório:**
no cmd: git clone https://github.com/Victoriabandeira-sys/CP2-Front-End-Tailwind.git

**2. Entre na pasta principal:**

cd CP2-Front-End-Tailwind

**3. Instale as dependências:**

npm install

**4. Compile o Tailwind CSS:**

npm run build

**5. Abra o projeto:**

Abra `CheckPoint-05-ES/index.html` utilizando o Live Server do VS Code.

## Durante o desenvolvimento

Para recompilar o CSS automaticamente:

npm run dev
